# Exports

Generated deliverables for this repo:

| File | Description |
|------|-------------|
| `VibeCoding_Presentation.pptx` | PowerPoint built from `presentation.html` (run `python3 scripts/export_html_to_pptx.py`) |

Each slide is a **full 1920×1080 viewport** screenshot (same as the browser window): clean slide area with no counter or nav chrome—so the PPTX matches what you see when you open the deck locally.

Temporary PNGs go to `.ppt_screenshots/` (gitignored) and are removed unless you pass `--keep-screenshots`.
